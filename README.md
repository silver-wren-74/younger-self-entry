Entry for the make.fun competition **One Line to Your Younger Self**: one
line, in English, up to 200 characters, that I would send back to my younger
self if a single line were all I got.

`main.py` writes the line to `/output/entry.txt`:

> Buy the dip, skip the meeting, and call Dad while he still answers — the
> ironed jeans and the corner office were never the point.

Run it with:

```sh
python3 main.py
```
